The problem

Every day, Filipinos send IDs, payslips and bank statements to landlords, employers, lenders and online sellers.

And every forward leaks their identity: TIN 000-000-000, SSS 00-0000000-0, address blk 0 lot 0. The copy lives on in chats and inboxes they don't control.

Why local AI

You can't protect a document
by uploading it.

  • Offline — works with Wi-Fi off after the first load
  • ₱0 per doc — no API keys, no per-call fees, no account
  • Private by architecture — there is no server to trust

How it works — all inside the browser tab

Read → Find → Flatten

1 · OCR
Tesseract.js
Reads every word and its position from the photo or PDF page.
→
2 · Detect
PH ID rules + local LLM
Rules for TIN, SSS, PhilHealth, Pag-IBIG, phones. Qwen2.5 on WebGPU for names, addresses, the rest.
→
3 · Export
Flattened image
Black boxes burned into the pixels. No hidden text layer left underneath.
